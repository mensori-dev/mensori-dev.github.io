# Демо-сайты

Одностраничники для малого бизнеса: `auto/`, `barber/`, `flowers/`, `salon/`.
Публикуются на GitHub Pages из ветки `main`, корень репозитория.

Демо предназначены для показа клиентам: работают калькуляторы и формы,
отправка заявок отключена, в шапке каждой страницы стоит пометка «демо».
Финальная версия и исходники передаются после оплаты.

Персонализация ссылки без правки кода:
