# mensoridev — сайт студии

Публикуется на GitHub Pages из репозитория `mensori-dev/mensori-dev.github.io`,
ветка `main`, корень. Адрес: `https://mensori-dev.github.io/`.

Демо-сайты живут отдельно: `https://mensori-dev.github.io/demos/` (репозиторий `demos`,
локально `C:\dev\demos`).

**Важно:** `/demos/` отдаётся project Pages из репозитория `demos`, а не из папки
`site/demos` этого репозитория. Одноимённая папка здесь никогда не публикуется —
GitHub отдаёт project site в приоритете. Правки демо делаются только в `C:\dev\demos`,
дублировать их сюда нельзя. Старая ссылка `/demo/atele/` — заглушка-редирект
на `/demos/atele/`.

## Файлы

- `index.html` — главная: hero, услуги, работы, цифры, процесс, контакты.
- `uslugi.html` — прайс и сроки.
- `raboty.html` — примеры работ.
- `privacy.html` — политика обработки персональных данных (152-ФЗ).
- `assets/site.css` — все стили, один файл, без сборки и внешних зависимостей.

## Что заменить перед публикацией

Телефон-заглушка `+7 900 000-00-00` и ссылки `wa.me/79000000000` стоят во всех файлах.
Заменить на настоящий номер:

```
Select-String -Path *.html -Pattern '900 000-00-00|79000000000'
```

В `privacy.html` заполнить `[ОПЕРАТОР]`, `[ИНН]`, `[EMAIL]`.

## Правила

- Дизайн: тёмный «редакционный» скелет — полноэкранный hero, крупная типографика,
  блоки-строки с номерами. Не повторять композицию демо-сайтов
  (`C:\dev\studio\docs\design\layouts-used.md`).
- Новый сайт — другой скелет. Сверяться с журналом.
- Формы заявок нет намеренно: нет бэкенда, заявки идут в WhatsApp и по телефону.
  Если появится форма — обязательна галочка согласия и `privacy.html` у формы.
